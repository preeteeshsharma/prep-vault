## Day 1 — DSA: Arrays, Trees & Core Data Structures

### DSA: Two Sum variant — "Add two integer numbers equal to target value"
- **Pattern / goal:** Hash map–based two-pointer approach to find pairs summing to a target; confirm you can articulate the trade-off between brute force O(n²) and optimised O(n) with space.
- **Approach:**
  - Start by coding a brute-force nested-loop solution (O(n²) time, O(1) space); trace through a concrete example (e.g., `[2, 7, 11, 15]`, target `9` → output `[0, 1]`).
  - Refactor to a single-pass hash map (O(n) time, O(n) space); explain why you store `target - num` as you iterate.
  - Handle edge cases: duplicates in array, negative numbers, target = 0, array length < 2.
  - Bonus: discuss three-sum and k-sum generalisations if time permits.
- **Time:** 45 min

### DSA: Tree Expansion / Collapse — "Implement a tree-like structure with node expand/collapse and add child functionality"
- **Pattern / goal:** Tree traversal, node state management, and structural mutations; practise representing hierarchical data and implementing stateful operations on immutable trees.
- **Approach:**
  - Define a `TreeNode` class with fields: `id`, `label`, `isExpanded` (boolean), `children` (list).
  - Implement `toggleExpanded(nodeId)` — find the node, flip `isExpanded`, return the modified tree (or mutate in place if mutable trees are acceptable).
  - Implement `addChild(parentId, newChild)` — find parent, append new node, return updated tree.
  - Trace a concrete scenario: expand node A, add node C under node B, collapse A, verify tree structure.
  - Discuss depth-first vs breadth-first traversal for finding nodes; consider performance if tree is very deep or wide.
  - Edge cases: null parent ID, duplicate IDs, circular references (if applicable), adding to a non-existent node.
- **Time:** 45 min
