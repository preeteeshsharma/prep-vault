## Day 1 — Foundational Data Structures & Algorithms

### DSA: Longest Substring Without Repeating Characters (LC 3)
- **Pattern / goal:** Sliding Window, Hash Set for efficient character lookup.
- **Approach:**
    - Initialize two pointers (left and right) and a hash set.
    - Expand the window with the right pointer, adding characters to the set.
    - If a character is already in the set, shrink the window from the left, removing characters until the duplicate is gone.
    - Track the maximum window size encountered.
- **Time:** 60 min

## Day 2 — Efficient Search & Optimization

### DSA: Merge Intervals (LC 56)
- **Pattern / goal:** Interval Merging, Sorting.
- **Approach:**
    - Sort the intervals based on their start times.
    - Iterate through the sorted intervals, merging overlapping ones into a new list.
    - If the current interval overlaps with the last merged interval, update the end of the last merged interval. Otherwise, add the current interval to the result.
- **Time:** 60 min

### DSA: Coin Change (LC 322)
- **Pattern / goal:** Dynamic Programming (Bottom-up).
- **Approach:**
    - Create a DP array `dp` where `dp[i]` represents the minimum number of coins to make amount `i`.
    - Initialize `dp[0]` to 0 and all other `dp[i]` to infinity.
    - Iterate from `i = 1` to `amount`, and for each `i`, iterate through the available `coins`.
    - If `i - coin >= 0`, update `dp[i] = min(dp[i], dp[i - coin] + 1)`.
- **Time:** 60 min

## Day 3 — Tree Structures & Priority Queues

### DSA: Binary Tree Maximum Path Sum (LC 124)
- **Pattern / goal:** Tree DFS, Recursion with global maximum tracking.
- **Approach:**
    - Implement a recursive helper function that returns the maximum path sum starting from the current node and going downwards (to one child).
    - Inside the helper, calculate the path sum that *includes* the current node as the peak (can include both children or just one). Update a global maximum with this value.
    - Handle negative contributions from children by taking `max(0, child_sum)`.
- **Time:** 60 min

### DSA: K Closest Points to Origin (LC 973)
- **Pattern / goal:** Heaps (Priority Queue), Euclidean Distance.
- **Approach:**
    - Use a max-heap to store `k` points.
    - Iterate through each point, calculate its squared Euclidean distance to the origin.
    - If the heap size is less than `k`, add the point.
    - If the heap is full and the current point's distance is less than the max-distance point in the heap, remove the max-distance point and add the current point.
- **Time:** 60 min

## Day 4 — Complex Array Manipulation & String Prefixes

### DSA: Trapping Rain Water (LC 42)
- **Pattern / goal:** Two Pointers, Dynamic Programming (pre-computation).
- **Approach:**
    - **Two-pointers:** Use left and right pointers. Maintain `max_left` and `max_right`. Move the pointer corresponding to the smaller of `max_left` or `max_right`. Add `(min(max_left, max_right) - height[pointer])` to total trapped water.
    - **DP (alternative):** Pre-compute `max_left[i]` and `max_right[i]` for all indices. Then, for each `i`, water trapped is `max(0, min(max_left[i], max_right[i]) - height[i])`.
- **Time:** 60 min

## Day 5 — Graph Dependencies & String Segmentation

### DSA: Course Schedule (LC 207)
- **Pattern / goal:** Graph, Topological Sort (DFS or BFS Kahn's Algorithm), Cycle Detection.
- **Approach:**
    - Build an adjacency list representation of the graph (prerequisites).
    - Calculate in-degrees for each node (number of prerequisites).
    - **BFS (Kahn's):** Initialize a queue with all nodes having in-degree 0. While queue is not empty, pop a node, decrement in-degrees of its neighbors. If a neighbor's in-degree becomes 0, add it to queue. Count processed nodes. If count equals total nodes, no cycle.
    - **DFS:** Perform DFS. Keep track of visited states: unvisited, visiting, visited. If DFS encounters a 'visiting' node, a cycle is detected.
- **Time:** 60 min

### DSA: Word Break (LC 139)
- **Pattern / goal:** Dynamic Programming, String Segmentation.
- **Approach:**
    - Create a boolean DP array `dp` of size `n+1`, where `dp[i]` is true if `s[0...i-1]` can be segmented. `dp[0]` is true.
    - Iterate `i` from 1 to `n`. For each `i`, iterate `j` from 0 to `i-1`.
    - If `dp[j]` is true AND `s[j...i-1]` is in the `wordDict`, then `dp[i]` is true. Break inner loop.
- **Time:** 60 min

## Day 6 — Data Serialization & Caching Mechanisms

### DSA: Serialize and Deserialize Binary Tree (LC 297)
- **Pattern / goal:** Tree Traversal (BFS/DFS), String Manipulation, Data Serialization.
- **Approach:**
    - **Serialization:** Use BFS (level-order traversal) or DFS (pre-order) to convert the tree into a string. Use a special marker (e.g., "null") for empty nodes. Separate node values with a delimiter (e.g., ",").
    - **Deserialization:** Parse the string back into a list of node values. Reconstruct the tree using the same traversal method (BFS for level-order, DFS for pre-order). For BFS, use a queue to manage parent nodes.
- **Time:** 60 min

### DSA: LRU Cache (LC 146)
- **Pattern / goal:** Hash Map + Doubly Linked List.
- **Approach:**
    - Use a `HashMap` to store `key -> Node` mappings for O(1) lookup.
    - Use a `DoublyLinkedList` to maintain the order of recently used items (MRU at head, LRU at tail).
    - When `get(key)`: If key exists, move its node to the head of the list. Return value.
    - When `put(key, value)`:
        - If key exists, update its value and move its node to the head.
        - If key doesn't exist:
            - Create new node. Add to hash map and head of list.
            - If capacity exceeded, remove LRU node (from tail) and its entry from hash map.
- **Time:** 60 min
