## Day 3 — Dynamic Programming

### DSA: Longest Increasing Subsequence (LeetCode 300)
- **Pattern / goal:** Dynamic Programming to find an optimal substructure in a sequence.
- **Approach:**
  - Define a DP array where `dp[i]` represents the length of the longest increasing subsequence ending at index `i`.
  - Iterate through the array, and for each element `nums[i]`, iterate through previous elements `nums[j]` where `j < i`.
  - If `nums[i] > nums[j]`, then `dp[i] = max(dp[i], 1 + dp[j])`.
  - The final answer is the maximum value in the `dp` array.
  - Consider the optimized O(N log N) solution using patience sorting with a tail array.
- **Time:** 60 min

## Day 4 — Heaps & Priority Queues

### DSA: Merge K Sorted Lists (LeetCode 23)
- **Pattern / goal:** Using a Min-Heap (Priority Queue) to efficiently merge multiple sorted data streams.
- **Approach:**
  - Add the head of each non-empty linked list to a min-heap, storing `(value, list_node)`.
  - Repeatedly extract the minimum element from the heap.
  - Append this element to the result list.
  - If the extracted node has a `next` element, add `(next_value, next_node)` to the heap.
  - Continue until the heap is empty.
- **Time:** 60 min

## Day 6 — Two Pointers & Hash Maps (Advanced)

### DSA: 3Sum (LeetCode 15)
- **Pattern / goal:** Combining sorting, two pointers, and hash maps to find combinations that sum to a target, while handling duplicates efficiently.
- **Approach:**
  - Sort the input array first. This is crucial for the two-pointer approach and skipping duplicates.
  - Iterate through the sorted array with one pointer `i`. This will be your first number.
  - For each `nums[i]`, use two pointers (`left` and `right`) to find pairs `(nums[left], nums[right])` in the *remaining* part of the array that sum to `0 - nums[i]`.
  - Move `left` and `right` inwards based on whether the sum is too small or too large.
  - Include logic to skip duplicate numbers for `i`, `left`, and `right` to ensure unique triplets in the result.
- **Time:** 60 min

## Day 7 — String & Dynamic Programming

### DSA: Word Break (LeetCode 139)
- **Pattern / goal:** Dynamic Programming or Backtracking with Memoization for string segmentation.
- **Approach:**
  - Define a boolean DP array `dp` where `dp[i]` is `true` if the substring `s[0...i-1]` can be segmented into words from the dictionary.
  - Initialize `dp[0] = true` (empty string can always be segmented).
  - Iterate from `i = 1` to `n` (length of string `s`).
  - For each `i`, iterate from `j = 0` to `i-1`.
  - If `dp[j]` is `true` and the substring `s[j...i-1]` is in the `wordDict`, then set `dp[i] = true` and break the inner loop.
  - The final answer is `dp[n]`.
- **Time:** 60 min
