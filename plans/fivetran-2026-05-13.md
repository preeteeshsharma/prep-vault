## Day 6 — Distributed systems patterns: consensus & ordering

### DSA: Serialize and Deserialize Binary Search Tree (LeetCode 449)
- **Pattern / goal:** BST encoding for network transmission; reconstruction with O(n) time.
- **Approach:**

### DSA: Longest Substring Without Repeating Characters (LeetCode 3)
- **Pattern / goal:** Sliding window with hashmap state; temporal ordering of character positions.
- **Approach:**
  - Two-pointer window; hashmap tracks last-seen index of each char.
  - On collision, move left pointer to right of previous occurrence.
  - Edge cases: all unique, all same character, empty string.
- **Time:** 45 min
