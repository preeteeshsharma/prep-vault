## Day 2 — Heaps & Graph Traversal

### DSA: LeetCode 703 — Kth Largest Element in a Stream
- **Pattern / goal:** Heap (min-heap) for maintaining top-k elements in streaming data; common at fintech/data companies.
- **Approach:**
  - Use a min-heap of size k; maintain invariant that heap contains k largest elements seen so far.
  - For each new element, compare with heap root; evict if necessary.
  - Code both `add()` (push element, heapify if size > k) and `findKthLargest()` (return root) operations.
  - Trace: stream `[4, 1, 5, 0, -1]`, k=2 → sequence of kth largest: `4`, `4`, `5`, `5`, `5`.
- **Time:** 45 min

## Day 4 — Arrays, Hashing & Optimization

### DSA: LeetCode 1481 — Least Number of Unique Integers after K Removals (Fivetran-style optimization)
- **Pattern / goal:** Greedy frequency-based removal; minimize distinct IDs (directly inspired by Fivetran's "bag with item IDs" problem).
- **Approach:**
  - Count frequency of each element; sort by frequency ascending.
  - Greedily remove entire groups starting from lowest-frequency elements until k removals exhausted or all groups removed.
  - Return count of remaining distinct elements.
  - Trace: `arr=[1,1,1,2,2,3]`, `k=2` → remove the two 2s and one 1 (or just the group [3]) → minimum distinct = 1 or 2 depending on greedy order.
