### Round Format & Setup



Fivetran labels its coding challenges as 60–90 minutes, conducted via video or in person. The "C1 Problem Solving" challenge is a fairly standard coding question, designed to determine a base level of problem-solving ability in the software language of your choice, delivered via HackerRank.





There is also a separate "C2 Coding Structure and Data Processing" challenge — a more focused problem evaluating your ability to interact with a codebase, think about code structurally, and perform basic data manipulation work. This is given as part of the onsite interview.





The C2 problem is given in Java, though interviewers are instructed to assist with minor language difficulties — a Python engineer ought to be able to pass with a quick review of Java language fundamentals.





You are expected to write executable code and check that all test cases pass

 — interviewers run your solution against their test suite live.

### Themes & Patterns

1. **All test cases must pass** — 

In the first technical assessment, be ready to write code that will give 100% output with all test cases passing.

 Several candidates were rejected despite having the right approach but missing edge cases.

2. **Conversational style is rewarded** — 

You're encouraged to ask questions about the problem and the merits of different options. The interview works best for both participants if it's a conversation.



3. **Verbally articulate your approach** — 

One Blind user noted: they were asked an easy HackerRank question, solved it in the first 15 minutes, then were asked follow-up questions and to explain their approach verbally.



4. **Technical coding rounds are taken by Senior Software Engineers (SSEs)** — 

The technical coding interview is taken by an SSE (~45 mins). The first 15 minutes cover Java and DB questions (e.g., static keyword, final, static vs. dynamic binding, foreign keys, normalization), followed by an LC medium DSA question on HackerRank.



5. **Follow-up rounds can involve a second distinct DSA problem** — 

Round 2 also starts with 1 LC medium question on HackerRank — expected to be 30 mins for coding + 15 mins for discussion on other topics.

### Preparation Tips (from candidates)

- 

Ensure you are well-versed in Java, SQL, and data structures. Practice medium-level LeetCode questions. Be prepared to explain your thought process and approach during live coding sessions, as interviewers appreciate candidates who can articulate their reasoning.


- 

One candidate advised: don't waste time understanding all of the existing codebase — start by solving the required logic first, then look in the codebase only for what you need.


- Passing all test cases is the bar — several candidates passed "in spirit" but were rejected for missed edge cases. Test your solution thoroughly before submitting.
- 

For senior roles specifically, technologies such as Docker and Kubernetes are also important

 (may come up in technical discussion portions).
