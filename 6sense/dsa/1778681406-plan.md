## Day 2 — String Algorithms, Graph Traversal & Tree Structures

### DSA: Palindromic Substrings — Identify & Count
- **Pattern / goal:** String algorithm for finding and counting palindromic substrings efficiently — use expand-around-center or Manacher's algorithm.
- **Approach:**
  - **Expand-around-center approach:** For each possible center (single char or between two chars), expand left/right while characters match. O(n²) time, O(1) space.
  - **Manacher's algorithm (bonus):** Linear time using a clever trick with a mirror array and the "center" variable. More complex but impressive for senior roles.
  - Count all palindromes, or count only *odd-length* / *even-length* variants as the problem specifies.
  - Trace "abaca" → palindromes: "a" (×3), "b", "c", "aba", "aca" → count 6.
- **Time:** 60 min
- **LeetCode:** #647 Palindromic Substrings
