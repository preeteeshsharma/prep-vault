## Day 2 — Dynamic Programming & String Manipulation

### DSA: LeetCode 1143 — Longest Common Subsequence (LCS)
- **Pattern / goal:** Classic DP table construction; **path reconstruction** (confirmed 6SENSE follow-up requirement).
- **Approach:**
  - Build the DP table bottom-up (O(m×n) time, space).
  - Trace back through the table to **print the actual LCS string**, not just its length.
  - Practice explaining the recurrence relation: `dp[i][j] = dp[i-1][j-1] + 1` if characters match, else `max(dp[i-1][j], dp[i][j-1])`.
  - Walk through a concrete example (e.g. "abcde" vs "ace") by hand.
- **Time:** 60 min

### DSA: LeetCode 647 — Palindromic Substrings
- **Pattern / goal:** String DP; enumerate and count palindromes; identify specific types (confirmed 6SENSE variant).
- **Approach:**
  - Solve using expand-around-center (O(n²) time, O(1) space) and DP table approach.
  - Extend: **identify and categorize** palindromes (e.g. odd-length vs. even-length, or by starting index).
  - Output indices and the actual palindromic substrings, not just the count.
  - Test on "ababa" and "aabaa" to ensure you can handle overlapping palindromes.
- **Time:** 55 min
