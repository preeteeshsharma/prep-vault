### 🧩 Confirmed Asked Questions (Firsthand Accounts)

1. **Dynamic Programming — LCS Variant: Given two sequences, solve a variant of the Longest Common Subsequence (LCS) problem. Follow-up: print the actual path/sequence, not just the length.**
   - Type: ✅ Confirmed asked

DSA Round 1 (60 minutes) focused on a dynamic programming problem, specifically a variant of the Longest Common Subsequence (LCS) algorithm, followed by a request to print the path.



2. **String / Palindromes — Palindromic Substrings: Count (and identify) specific types of palindromic substrings within a given string.**
   - Type: ✅ Confirmed asked
   - Source: [EnginEBogie #1340](https://enginebogie.com/interview/experience/6sense-senior-software-engineer/1340) — 2024/2025

DSA Round 2 (60 minutes) involved a string manipulation problem focused on identifying and counting specific types of palindromic substrings.



3. **Graph / DFS — 2D Grid Word Search: Given a 2D character grid and a list of words, find and output the starting index of each word. Words can be searched in all 8 directions (in a straight line). Constraint: must not traverse the grid once per word — requires an optimal, batched approach.**
   - Type: ✅ Confirmed asked (OA/HackerRank screen, used as DSA gate)
   - Source: [LeetCode Discuss](https://leetcode.com/discuss/interview-question/1316022/6sense-oa-hackerrank/) — 2021
   - Notes: 

Given a 2-D grid of characters and a list of words to be searched in the grid, output the starting indexes from which each word starts. Words can be searched in all 8 directions but must be in a straight line. The optimal solution should not traverse or process the grid once per word.

### 📊 Difficulty & Format

- 

Questions are easy to medium level LeetCode. One with good DSA practice will solve it easily.


- 

Coding questions were LeetCode medium and hard, but interviewers gave hints towards the optimal solution.


- 

The senior loop has **two dedicated DSA rounds**, each 60 minutes, each focused on a single problem.


- 

After a system design phone screen, the onsite includes another system design and 3 coding rounds.

### 🔁 Themes & Patterns

Based on all sources, the DSA round at 6sense for SSE consistently hits these topic areas:

| Topic | Frequency |
|---|---|

| **Dynamic Programming** | 🔥 Confirmed (LCS variant + path printing) |

### 💡 Preparation Tips (From Candidates)

- 

Practice coding problems on platforms like LeetCode or HackerRank, focusing on **medium to hard difficulty** levels, especially in Java and Python.


- 

Be ready to solve problems in real-time, as interviewers may ask you to explain your thought process while coding.


- On the DP question, candidates were expected not just to solve but also to **reconstruct and print the path** — so know how to backtrack through DP tables.
- For the word search / grid question, the key signal was an **optimal batched solution** — naive O(n × grid) was explicitly called out as insufficient.
